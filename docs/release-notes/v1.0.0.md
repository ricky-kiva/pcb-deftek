# PCB Deftek 1.0.0

First stable release. The complete essential feature set from `specs/mission.md` §5.1 is implemented and verified: defect detection for all nine classes, file and batch inspection with ETA, live camera inspection with overlays and telemetry, inspection history, the interactive pan/zoom defect viewer, the statistics dashboard, audit-ready PDF export, and settings.

## Added

- Release notes are now kept per version under `docs/release-notes/` and published verbatim, starting with this file.
- Live Detection view-model regression coverage for the async UI dispatch path introduced during the 0.10.0 hardening work.

## Changed

- Version identity is now `1.0.0` (`ProductVersion` included in the published executable).
- `FileDetectionViewModel` runs its post-processing UI updates through a single guarded helper instead of three repeated dispatcher checks; behavior is unchanged.
- The release workflow validates the full tag version and passes it to packaging, so pre-release tags no longer produce final-version asset names.

## Fixed

- Defect bounding boxes in the inspection viewer were drawn at a different place than their clickable regions: the scene used a `LayoutTransform`, which applies the zoom scale but drops the pan/centering translation, while hit testing read the offset from the viewport model. The scene now uses a `RenderTransform`, so the drawn boxes, click targets, panning, focus and viewport cropping share one mapping. Covered by a regression test that asserts the rendered marker rectangle equals the model mapping at fit and after focus zoom.
- Duplicate `<p>` markup in the README badge section (the CI badge rendered as an empty paragraph).

## Known Limitations

- Release executables are signed with a self-signed certificate; Windows reports the publisher as untrusted until a publicly trusted code-signing certificate is used. Signatures and RFC 3161 timestamps verify.
- Multi-instance execution is allowed and not guarded.
- Splash branding is deferred.
- Large video-file processing and corporate identity/custom storage paths remain future enhancements (`specs/mission.md` §5.2).
